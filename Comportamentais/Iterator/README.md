## Design Patterns: Iterator
Percorrer os itens de uma coleção sem preciar saber como ela foi criada.
---
Analogia:
Pense em um Guia de Turismo num museu:
O museu possui centenas de obras organizadas de formas diferentes em várias salas.

Você não precisa saber o mapa do prédio nem como as salas se conectam para ver as artes.

O guia de turismo controla o percurso para você, um item de cada vez.

---
Quando Usar:
- Para esconder coleções complexas
- Para reutilizar algoritmos de travessia
- Múltiplos percursos simultâneos
