## Design Patterns: Interpreter 
Para resolver problemas de tradução de linguagens ou expressões.
---
Onde ele é usado na prática?

- Expressões Regulares (Regex): Avaliar se um texto segue um determinado padrão.

- Formatadores e Parsers: Interpretar comandos SQL simples, arquivos de configuração, JSON/XML customizados.

- Calculadoras e Linguagens de Script: Avaliar expressões matemáticas ou comandos de automação criados por usuários.
